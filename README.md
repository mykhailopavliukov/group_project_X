## Бриф: 
```
«У місті є кілька станцій прокату. На кожній станції стоять велосипеди. Велосипед
буває звичайний або електричний, у кожного є номер.
Клієнт має ім'я та баланс на рахунку. Він може взяти велосипед зі станції,
покататись певну кількість хвилин і повернути велосипед на будь-яку станцію.
Хвилина на звичайному велосипеді коштує 2 грн, на електричному 5 грн. Гроші
списуються з балансу клієнта після повернення.
Адміністратор хоче бачити, скільки велосипедів стоїть на кожній станції, і скільки
грошей мережа заробила загалом.»
```

## Демоваріант

```
Роль 4 робить git pull, запускає файл з main(). Демо-сценарій, який має пройти ваша
програма:
1. Створити 2 станції. 
2. Створити 4–5 велосипедів (і звичайні, і електричні) та поставити їх на станції.
3. Створити 2 клієнтів з різним балансом.
4. Провести щонайменше 3 поїздки між станціями.
5. Спробувати взяти велосипед на станції, де велосипедів не залишилось, і показати
   зрозуміле повідомлення.
6. Показати баланс клієнтів після поїздок.
7. Показати звіт адміністратора: скільки велосипедів на кожній станції і скільки
   мережа заробила загалом. 
```

1. Адміністратор створює станції
2. Адміністратор створює велосипеди і розподіляє по станціями
3. Адміністратор створює двох клієнтів
4. Адміністратор запускає симуляцію поїздок з певною кількістю
5. Тестовий варіант - взяти велосипед де немає їх, і зробити виняток або якесь повідомлення
6. Вивести рахунки клієнтів під кінець
7. Згенерувати звіт для адміністратори

## Ролі

1. Усе, що стосується велосипедів і станцій - **Михайло** (bicycle_station) 
2. Усе, що стосується клієнта та його балансу - **Артем У.** (client)
3. Поїздки: взяти велосипед, повернути велосипед, порахувати вартість, облік
   загальної виручки мережі - **Гоша** (system)
4. Запуск: файл з функцією main(), тестові дані, звіт адміністратора та 2–3
   перевірки через assert. Також створює репозиторій - **Артем М.** (main)
